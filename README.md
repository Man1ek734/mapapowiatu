# Mapa Powiatu Opatowskiego

Interaktywna mapa internetowa oparta na **Leaflet + OpenStreetMap + Overpass API**.

## Funkcje
- gastronomia: restauracje, kawiarnie, bary i fast food,
- zabytki i atrakcje turystyczne,
- noclegi,
- trasy rowerowe,
- sport i rekreacja,
- zdrowie,
- transport, parkingi, stacje paliw i ładowarki,
- urzędy i usługi publiczne,
- sklepy,
- wyszukiwarka i filtry,
- lokalizacja użytkownika,
- automatyczne pobieranie aktualnych danych z OpenStreetMap.

Projekt jest statyczny i przygotowany do działania na GitHub Pages.
